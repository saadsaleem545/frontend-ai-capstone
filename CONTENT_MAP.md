# CTA Strategy

The portfolio uses a single overall goal: **get visitors to explore my work and eventually contact me about an opportunity.**

The CTAs therefore create a simple progression:

**Home → View my projects → View project → View live demo / GitHub → Get in touch**

Each page supports this progression instead of introducing unrelated actions.

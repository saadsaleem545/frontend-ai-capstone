# Project Instructions

## Project

Frontend AI Engineering capstone project.

## Stack

- HTML
- CSS
- JavaScript
- Node.js
- Git
- Cursor AI

## Development Conventions

- Keep code simple, readable, and maintainable.
- Use semantic HTML where applicable.
- Use clear and descriptive variable and function names.
- Avoid unnecessary dependencies.
- Keep components and files focused on a single responsibility.
- Do not commit secrets, API keys, or environment variables.
- Test changes before committing them.
- Use Conventional Commits for Git commit messages.

## Git Commit Convention

Use this format:

`type(scope): description`

Examples:

- `feat(ui): add navigation`
- `fix(form): validate email input`
- `docs(readme): improve project documentation`

## AI Development Rules

- Prefer small, focused changes.
- Do not modify unrelated files.
- Check existing project conventions before introducing new patterns.
- Review changes before committing them.

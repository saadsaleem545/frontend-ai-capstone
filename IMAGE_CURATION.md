# Image Curation

## Final Image Set

The portfolio uses real screenshots of the working React application as the primary project visuals.

### Keepers

* `settings.png` — Main settings interface
* `profile.png` — Profile settings
* `preferences.png` — User preferences
* `notifications.png` — Notification settings
* `security.png` — Security settings
* `health.png` — Health-check page

These images were captured from the deployed application so they show the actual implemented work rather than AI-generated replacements.

## Real Captures vs AI

I chose real screenshots for all core project visuals because they provide direct evidence of the application's functionality and design.

AI-generated imagery is not used as a replacement for the actual project screenshots. Supporting visuals may be used only when they improve the presentation without distracting from the work.

## Rejected Image

I rejected a generated background that was too detailed and visually distracting. Its strong visual elements competed with the application screenshots instead of supporting them.

The final direction prioritizes simple visuals, negative space, and consistency with the project's blue and teal identity.

## Curation Decision

The final image set was intentionally kept small. Each image has a clear purpose and maps directly to a real screen in the application.

The goal was to make the portfolio feel consistent while keeping the actual work as the main focus.
